# CR Analyzer — Clash Royale Overlay

Оверлей реального времени для Clash Royale. Анализирует арену через захват экрана и показывает рекомендации по расстановке карт поверх игры.

## Функции
- Захват экрана через MediaProjection (без рута)
- Анализ эликсира, HP башен, фазы игры
- Рекомендации по расстановке с указанием приоритета
- Оверлей поверх игры (TYPE_APPLICATION_OVERLAY)
- Стрелки от карты в руке к рекомендуемой точке

## Сборка через GitHub Actions
1. Fork репозиторий
2. Push в `main`
3. Actions → Build APK → скачай артефакт `cr-overlay-debug`

## Установка APK
1. Разрешить установку из неизвестных источников
2. Установить APK
3. Запустить → выдать разрешение на отображение поверх окон
4. Выдать разрешение на захват экрана
5. Запустить Clash Royale
